## Introduction

Passbolt Windows 2.16.0 "Superstylin" introduces custom themes to personalize your workspace and also drives performance improvements on sharing operations, updates dependencies, and brings in essential security fixes.

## Themes

Passbolt Windows 2.16.0 adds two new custom theme options, Sakura and Layette, providing enhanced personalization for the user's workspace appearance.

These themes allow users to adapt the interface to their personal preferences while maintaining consistent user experience throughout the application.

If you have an idea for a new theme let us know on the Community Forum.

## Maintenance and Security

A detailed security bulletin will follow with more information about the security issues addressed in this release. In addition, routine dependency upgrades have been completed to keep the application fast and secure.

## Conclusion

Many thanks to everyone who provided feedback, reported bugs and contributed to making Passbolt better.
